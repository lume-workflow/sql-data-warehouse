# Building the Data Warehouse (Data Engeneering)

### Objetivo

Desenvolver um Data Warehouse usando SQL Server para consolidar dados de venda, habilitar relatórios analíticos e tomada de decisão baseada em dados.

### Especificações

**Fontes de Dados**: Importação de CSV disponibilizados por Baara (ERP e CRM).

**Qualidade de Dados**: Limpeza e resolução de problemas para facilitar análise.

**Integração**: Combinar as duas fontes em um modelo de dados único e user-friendly para queries analíticas.

**Escopo**: Foco no dataset mais recente, sem necessidade de historização de dados.

**Documentação**: Providenciar documentação clara do modelo de dados para ajudar tomada de decisões tanto de stakeholders quanto de analistas de dados.
